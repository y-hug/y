# Vision Platform Clone Scripts

This repository includes utility scripts to clone the vision-platform repository from Gitee.

## Usage

### For Unix/Linux/macOS:

```bash
bash clone-vision-platform.sh
```

or

```bash
./clone-vision-platform.sh
```

### For Windows:

Double-click `clone-vision-platform.bat` or run in Command Prompt:

```cmd
clone-vision-platform.bat
```

## What it does

The scripts will clone the vision-platform repository from:
```
https://gitee.com/zehua-zhao/vision-platform.git
```

The cloned repository will be placed in a `vision-platform/` directory in the current location.

## Note

- The cloned `vision-platform/` directory is excluded from version control (added to `.gitignore`)
- Ensure you have `git` installed before running these scripts
- An internet connection is required to clone the repository
